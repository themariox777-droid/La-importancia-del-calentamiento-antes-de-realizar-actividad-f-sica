: El calentamiento es el conjunto de ejercicios generales y específicos que se realizan antes de cualquier actividad física con el objetivo de preparar al organismo para un esfuerzo mayor. En el ámbito de la Cultura Física y el entrenamiento deportivo, no es solo un trámite, sino una fase fundamental que marca la transición entre el estado de reposo y el de máxima activación neuromuscular.
